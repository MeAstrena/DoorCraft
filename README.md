# DoorCraft - интернет-магазин дверей

## Описание
Учебный интернет-магазин по продаже дверей. Реализован в рамках курсовой работы на 1-м курсе.

## Технологии
- HTML
- CSS
- Java

## Функциональность
- Каталог товаров с фильтрацией по категориям
- Корзина товаров
- Форма оформления заказа с валидацией полей
- Адаптивная вёрстка под мобильные устройства

## Технологии
- HTML
- CSS
- JavaScript

## Моя роль
Полная разработка проекта: от дизайна до вёрстки и тестирования функционала.
